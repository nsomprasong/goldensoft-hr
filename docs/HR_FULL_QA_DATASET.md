## 1. วิธีสร้างข้อมูล

```bash
# 1) Platform — องค์กร / สาขา / Auth
cd goldensoft-platform
npm run seed:full-qa

# 2) HR — master + พนักงาน / ตำแหน่ง / ตารางงาน / ลงเวลา / ลา / เบิกล่วงหน้า
cd ../goldensoft-hr
npm run seed:full-qa
```

> ตารางงาน Full QA ถูก **เผยแพร่ (PUBLISHED)** และจัดพนักงานเข้าตารางแล้ว — หน้า “ตารางงานของฉัน / ลงเวลา” จะเห็นช่วง มิ.ย.–ก.ค. 2569  
> ถ้าข้อมูลเก่ายังเป็นร่าง: `npx tsx scripts/repair-full-qa-schedules.ts`


ล็อกอิน: `http://localhost:3000/login` → เลือกองค์กร **อัลฟ่า** หรือ **เบต้า**

> หมายเหตุ: HR seed ใช้เวลานาน (สร้างลงเวลาทุกวันทำงาน ~2 เดือน × 40 คน)

## 8. รูปแบบลงเวลา / ลา / เบิก (1 มิ.ย. – 31 ก.ค. 2569)

ตารางงานต่อสาขา (`FQA_JUNJUL_HQ` / `FQA_JUNJUL_B2`) สถานะ **PUBLISHED** — พนักงานถูกจัดเข้าทุกวันในช่วงนี้ (วันทำงาน + เสาร์–อาทิตย์เป็นวันหยุด)

เฉพาะวันจันทร์–ศุกร์มีลงเวลา (ข้ามเสาร์–อาทิตย์ / วันหยุด)

| กลุ่ม fixture | พฤติกรรมหลัก |
|---------------|--------------|
| `late` | มาสายเกือบทุกวันที่ `date % 3 === 0` (+ ขาดบางวัน) |
| `absent` | ขาดวันที่ 5, 19 และ 8 ก.ค. + สายบางวัน |
| `leave` | ลาวันที่ 10–11 มิ.ย. และ 3 ก.ค. (APPROVED) + คำขอลารออนุมัติ “วันนี้” |
| `night` | กะกลางคืน — สาย/ขาดตามรอบ |
| `advance` | ลงเวลาปกติเป็นส่วนใหญ่ + เบิกล่วงหน้า |
| `normal` / `viewer` | มาตรงเวลาเป็นหลัก (มีสาย/ขาดเบา ๆ) |

เบิกล่วงหน้าต่อองค์กร:

- พนักงาน HQ กลุ่ม `advance` → สถานะ **APPROVED** 2,000 บาท (2 งวด)
- พนักงาน B2 กลุ่ม `advance` → สถานะ **SUBMITTED** 3,000 บาท (รออนุมัติ)

งวดเงินเดือน: ครึ่งเดือน มิ.ย. + ก.ค. 2569
